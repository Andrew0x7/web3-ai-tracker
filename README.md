# Web3 AI Automation Ecosystem

A production-ready, event-driven AI automation platform for Web3 token security analysis and automated trading.

## 🚀 Features

- **Real-time Token Scanner**: Monitors Solana and Base networks for new token launches
- **AI-Powered Risk Analysis**: Automated rugpull detection using multi-factor security scoring
- **Automated Trading Agent**: Executes trades based on risk management parameters
- **Live Dashboard**: Real-time metrics, charts, and execution logs
- **Telegram Integration**: Webhook alerts for critical events

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, TypeScript, TailwindCSS
- **Charts**: Recharts
- **AI Agents**: Claude Code, OpenClaw, Hermes Agent
- **Deployment**: Vercel

## 📊 System Architecture

```
Token Scanner → Risk Analyzer → Trading Agent → Telegram Alerts
     ↓              ↓               ↓
  Dashboard ← Real-time Metrics ← Execution Logs
```

## 🔧 Installation
